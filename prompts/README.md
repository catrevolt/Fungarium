# Промпты Fungarium

Этот репозиторий используется для сохранения промптов текущего чата проекта Fungarium по указанию пользователя от 9 октября 2026 года.

Исходное указание:
> https://github.com/catrevolt/Fungarium.git используй в этом чате этот репозиторий для сохранения промтов

Промпты сохраняются в папке `prompts/` отдельными Markdown-файлами с датой и коротким названием. Для каждого задания сохраняются исходный запрос, уточнения пользователя и итоговый рабочий промпт, когда он сформирован. Новые версии сохраняются с сохранением истории изменений.
